# 🎓 Favourite Student List Portal

A responsive React.js web application for managing and viewing student information. 
The application allows users to browse students, view their details, and add or remove students from a favourite list.

## 🚀 Features

- 📋 Display student information
- ❤️ Add students to Favourite Students
- ❌ Remove students from favourites
- 🔍 View detailed student information
- 🪟 Student details displayed using a modal
- 📱 Responsive user interface
- 🧭 Navigation using React components
- ⚛️ Reusable React components
- 🔄 State management using React Context API
- 🎨 Styled using Tailwind CSS
- 💻 Clean and component-based project structure

## 👨‍🎓 Student Information

The student details include:

- Student Name
- Student ID
- Course
- Email ID
- Phone Number
